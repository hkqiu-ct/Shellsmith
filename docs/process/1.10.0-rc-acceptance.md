# 1.10.0-rc 验收与稳定版门槛

状态：`rc`。当前候选版本 `1.10.0-rc.1`，目标是决定进入 `1.10.0` 稳定版、发 `1.10.0-rc.2`，还是保持 rc。

## 1. 验收范围

本清单只覆盖 1.10.0 已有能力，不新增功能：

- DEXB v6/v7、PVM2、路由 assets、业务 SO、PAS2
- RASP、Root/调试策略、FLAG_SECURE、ADB 策略
- BYOS `device_approval`（Play 模式无账号时保持 `unverified`）
- AAB 本地 bundletool 链（不代表 Play 分发）
- iOS freeRASP、`block_on_critical`、App Attest 客户端（如有真机）
- 三平台安装包、更新清单、签名状态

## 2. 设备矩阵

| 平台 | 最低要求 |
|---|---|
| Android | API 21、26、29、31、35 各至少一台；arm64 + armeabi-v7a |
| Android 页面 | 4 KB 页至少一台；16 KB 页设备有则加测 |
| 厂商 | 至少一个小米/华为/OPPO/vivo 等主流 ROM |
| 工控 | Android 4.4/armeabi-v7a 如有发布需求 |
| iOS | iOS 13+ 真机；freeRASP 与 App Attest 分开记录 |
| 桌面 | Windows/macOS/Linux 安装、启动、更新一次 |

## 3. 功能验收

每个设备至少记录：

- 安装、首次启动、冷启动、热启动
- 登录、核心业务、关键页面
- PVM2 必保方法
- ARouter/TheRouter 页面跳转（启用路由 assets 时）
- 业务 SO 加载
- 清数据、覆盖升级、卸载重装
- 截图/录屏/ADB 策略
- 启动 TotalTime、PSS、崩溃/ANR

失败样本必须保留，不得只记录成功。

## 4. BYOS

### 4.1 `device_approval`

必须验证：

- 产物注册
- 未知设备待批准
- 管理员批准
- 首次取钥与缓存启动取钥
- 错包名/错证书/错授权方式
- 重放/并发重放
- 撤销设备/产物后拒绝
- 主密钥轮换、数据库备份恢复
- 日志不含 IKM、Authorization、完整证明

### 4.2 `play_integrity`

无 Play 账号时：

- 只运行 mock/单元测试
- 状态标记 `unverified`
- 不宣称 Play 分发已验证

## 5. AAB 本地链

不需要 Play 账号：

```bash
bundletool validate --bundle=protected.aab
bundletool build-apks --bundle=protected.aab --output=protected.apks \
  --ks=... --ks-key-alias=... --ks-pass=env:...
bundletool install-apks --apks=protected.apks --device-id=<serial>
```

验证：

- base + install-time dynamic feature
- 条件/按需模块（如有）
- Asset Pack（如有）
- split 安装、清数据、覆盖升级

结论必须写“本地 bundletool 通过，Google Play 分发未验证”。

## 6. 发布链

- Release 工作流手动触发
- `CI 通过` 为 main 必需检查
- macOS Developer ID/公证状态
- Windows Authenticode 状态
- 更新签名私钥备份
- SHA-256、`latest.json`、`.sig` 校验

## 7. 证据

- `bash scripts/check-evidence-ready.sh --baseline`
- `docs/evidence/chain-a-report.md`、`chain-b-report.md` 更新
- 每个实验绑定输入哈希、脚本版本、设备/环境
- 未验证项保留

## 8. 稳定版门槛

满足以下条件才发 `1.10.0`：

- rc 阶段无 P0/P1 未解决
- 设备矩阵通过
- 路由 assets 真机通过
- BYOS `device_approval` 通过
- AAB 本地链通过
- 三平台安装包启动通过
- 安装包签名状态明确
- 证据门禁通过
- 未验证项在 Release Notes 中保留

不满足时：

- 有 P0/P1：发 `1.10.0-rc.2`
- 只有 P2/P3/文档：可评估直接发 `1.10.0`
- 外部能力缺失：稳定版可作为 APK/桌面版发布，但 Play/App Store 能力保持 `unverified`
