# 攻击树（证据基线）

状态：`baseline`。

## 链路 A：DEXB + PVM2 静态恢复

```text
恢复业务代码
├─ 直接解包 APK
│  ├─ 提取 classes*.dex / assets / lib
│  └─ 识别 MSHD / DEXB 载荷
├─ 恢复 DEX
│  ├─ 从包内材料派生 IKM（v6）
│  ├─ 解密 ChaCha20-Poly1305
│  └─ 解压 1~3 层 zstd
├─ 恢复 PVM2
│  ├─ 解析 code.bin v4
│  ├─ 解析 PVM2 镜像 v7~v9
│  ├─ 还原 morph/寄存器映射/操作码
│  └─ 重建方法语义
├─ 恢复 Native/SO
│  ├─ 解密 .text / PSO2
│  └─ 还原函数区域
└─ 绕过运行时
   ├─ 修改签名/证书
   ├─ Hook 解密/加载
   ├─ 提取私有缓存
   └─ 内存 dump
```

**关键度量：** 恢复一个方法、一个 DEX、整包的步骤/时间/工具；同一恢复器跨构建复用程度；语义重建成功率。

## 链路 B：BYOS 取钥

```text
获取 IKM
├─ 网络侧
│  ├─ 重放请求
│  ├─ 篡改包名/证书/授权方式
│  ├─ 时钟回拨
│  └─ 转发到已授权设备
├─ 设备侧
│  ├─ 伪造设备签名
│  ├─ 未批准设备登记
│  ├─ 撤销后继续取钥
│  └─ 提取已进入进程的 IKM
├─ 服务端侧
│  ├─ 数据库/备份读取
│  ├─ KMS/HSM 权限滥用
│  ├─ 主密钥轮换错误
│  └─ 审计/日志泄漏
└─ Play 模式
   ├─ 伪造/重放 Integrity token
   ├─ 包名/versionCode/证书不匹配
   └─ Google 服务不可用
```

**关键度量：** 每个负面用例是否在预期层拒绝；拒绝证据是否可复现；撤销/轮换/恢复后的状态是否一致。
