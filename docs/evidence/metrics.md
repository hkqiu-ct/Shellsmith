# 度量定义（证据基线）

状态：`baseline`。阈值由每个版本预注册，不能事后调整。

## Chain A

| 指标 | 定义 | 当前状态 |
|---|---|---|
| 必保方法覆盖率 | 通过最终产物核验的必保方法 / 必保清单 | 目标 100% |
| 选中方法覆盖率 | 通过产物核验的方法 / 选择范围全部方法 | 需按样本报告 |
| 指令字节覆盖率 | 通过核验方法的输入指令字节 / 选中方法总字节 | 需按样本报告 |
| 恢复步骤数 | 从 APK 到可读业务代码的操作步骤 | 需基线 |
| 恢复耗时 | 熟练分析者完成恢复的时钟时间 | 需基线 |
| 跨构建复用 | 同一恢复器/规则在新构建上的适配量 | 需基线 |
| 明文窗口 | 明文 DEX/assets/SO 在磁盘/内存的存在时间 | 需基线 |
| 启动开销 | 冷启动中位数/P95 | 需预算 |
| PSS 增量 | 启动后主进程 PSS 增量 | 需预算 |

## Chain B

| 指标 | 定义 | 当前状态 |
|---|---|---|
| 负面用例拒绝率 | 按预期层拒绝的用例 / 全部负面用例 | 目标 100% |
| 重放唯一性 | 并发重放成功次数 ≤ 1 | 目标 |
| 撤销生效 | 撤销后后续取钥失败 | 目标 |
| 轮换/恢复 | 轮换、备份恢复后旧产物可解封 | 目标 |
| 日志泄漏 | 日志中不出现 IKM/Authorization/完整证明 | 目标 |
| 外部依赖可用性 | KMS/HSM/Play/DB 故障时的失败关闭 | 目标 |

## 证据质量

- 每个数字绑定输入哈希、脚本版本、设备/环境。
- 失败样本保留，不清洗。
- 没有原始输出的数字不进入报告。
